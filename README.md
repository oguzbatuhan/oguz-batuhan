# Oğuz Batuhan — Kişisel Portfolio

Bu proje hem kişisel web sitem hem de bir öğrenme alanım. Yazılım geliştirme
becerilerimi gerçek bir proje üzerinde geliştirmek, öğrendiğim şeyleri
uygulamaya dökmek amacıyla sıfırdan yazıyorum.

## ✨ Özellikler

- Karanlık tema (Tailwind `@theme` ile özelleştirildi)
- Responsive tasarım (mobilde açılır menü, masaüstünde yatay nav)
- Scroll sırasında aktif section'a göre nav linkini otomatik vurgulama
  (`IntersectionObserver` ile)
- Etkileşimli terminal bileşeni — `help`, `history`, `joke`, `bug`, `debug`, `coffee`, `fortune`, `sudo`, `sleep`, `deploy`, `exit`, `clear`,
  `contact`, `clear` komutlarını destekliyor
- Özel yüklenen fontlar: Space Grotesk (başlık/metin), JetBrains Mono (terminal)

## 🛠️ Kullanılan teknolojiler

- Vite — build aracı
- Tailwind CSS v4 — stil
- Iconify (Tailwind plugin) — ikonlar
- Vanilla JavaScript — herhangi bir framework kullanılmadı
- GitHub Actions + GitHub Pages — otomatik deploy
